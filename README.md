# Охотница за гробницами

Unity-версия HTML-прототипа «Охотница за гробницами». Героиня — Ада Рейвенкрофт, расхитительница гробниц (отсылка к Ларе Крофт, но не сам персонаж). Ядро — исследование гробницы из плит картами-инструментами; вокруг него — город, вертолёт, карта экспедиций, аукцион артефактов и лавка снаряжения.

Unity `6000.6.5f1`, 2D, встроенный рендер, uGUI. Сцена — `Assets/_Project/Scenes/Main.unity`: в ней только камера и объект `Game`, весь интерфейс строится из кода при запуске. Если сцены нет, меню **Tomb → Setup → Rebuild Main Scene** соберёт её (при первом открытии проекта это происходит само).

Вся графика — пиксельные спрайты 12×12 и 16×16, записанные строками в `Core/Pixel.cs`, и процедурные текстуры (кирпич, шумы плит и пола, карта города и мира в `UI/MapArt.cs`). Внешних ассетов нет.

## Цикл игры

1. **Город Эшфорд.** Пиксельная карта с четырьмя точками:
   - **Особняк** — сводка, рюкзак и коллекция карт;
   - **Вертолётная площадка** рядом с особняком — открывает карту экспедиций;
   - **Аукционный дом** — продажа артефактов;
   - **Лавка снаряжения** — покупка карт в коллекцию (хозяин — Старый Гарри).

   Вверху — монеты, топливо, рюкзак и число карт. Ада подсказывает следующий шаг.
2. **Карта экспедиций.** Шесть гробниц (Рим, Крит, Египет, Майя, Тибет, Китай) со своим размером, расходом топлива, числом артефактов и частыми препятствиями. Разграбленные — серые. После разграбления появляется новая гробница уровнем выше. Топливо покупается здесь, 15 монет за канистру.
3. **Сборы.** В сумку экспедиции — до 14 карт из коллекции; «Собрать сам» подбирает набор под гробницу.
4. **Перелёт.** Вертолёт летит над картой мира (камера ×3), облака, след, посадка. Можно пропустить.
5. **Гробница.** Плиты на квадратной сетке, открывать можно только соседей открытых по стороне. Препятствия на рубашке снимаются картами, тьма прячет то, что под ней. Каждые два переворота — новая карта из сумки. Находки: сундук, склад, алтарь (карта на выбор), монеты, **артефакты** (в рюкзак), ловушка, обвал, выход под печатью. Выйти через выход — гробница разграблена. **Эвакуация** — в любой момент, пилот забирает половину монет. Неиспользованные карты возвращаются в коллекцию. Оформление (кирпич, плиты, пол) — по культуре гробницы.
6. **Аукцион — живые торги.** Выставляете артефакт, пять коллекционеров с портретами перебивают ставки, «Раз! Два! Продано!». Каждый переплачивает за свои культуры. Торги можно ускорить ×3.

Эффекты: перелёт карты в плиту, частицы под каждый инструмент (осколки, искры, угольки, дым, лёд, руны, взрыв с тряской рамки, волна света фонаря), переворот плиты, всплывающие надписи, карты летят в руку, выпавшие из руки краснеют и падают, артефакт улетает в рюкзак.

## Управление

Мышь. Выбрать карту в руке → нажать на подсвеченную плиту. Esc — снять выбор или закрыть окно.

## Масштаб окна

Сцена 1280×720, `CanvasScaler` в режиме Expand: игра целиком помещается в любое окно и масштабируется, лишнее место заполняет фон. Окно плеера — 1280×720, растягивается.

## Сохранение

`PlayerPrefs`, ключ `tomb-hunter-save-v1` (JSON через `JsonUtility`). Сбросить — **Tomb → Reset Save** или кнопка «Сброс» в панели «Отладка прототипа» в городе (двойное нажатие). Там же +100 монет и +3 топлива.

## Код

- `Scripts/Runtime/Core` — данные и логика без интерфейса:
  - `Data.cs` — препятствия, карты, находки, культуры и артефакты, редкости, коллекционеры, стартовые гробницы, карта мира;
  - `Model.cs` — сохраняемые классы и сидированный генератор;
  - `Run.cs` — экспедиция: генерация, карты, перевороты, находки, итоги;
  - `MetaLogic.cs` — новые гробницы, автосборы, торги, подсказки, сохранение;
  - `Pixel.cs` — спрайты из строк и процедурные текстуры.
- `Scripts/Runtime/UI` — интерфейс (`Game` — partial-класс по экранам), `Fx` — частицы и твины, `Kit` — кирпичики uGUI.
- `Scripts/Editor/TombSetup.cs` — сборка сцены и настроек, сборка под macOS (**Tomb → Build → macOS**).

## Тесты

- EditMode (`Tests/EditMode/LogicTests.cs`): детерминированная генерация, 60 экспедиций ботом (карты возвращаются, артефакты в рюкзаке), рост ставок на торгах, новая гробница на суше, сохранение туда-обратно.
- PlayMode (`Tests/PlayMode/ScreensTests.cs`): проходит все экраны, играет гробницу кликами и снимает скриншоты в `Screenshots/`.

Из командной строки:

```bash
Unity -batchmode -projectPath . -runTests -testPlatform EditMode -testResults edit.xml
Unity -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults play.xml
```

## Отличия от HTML-прототипа

- Текст набран встроенным шрифтом Unity, а не пиксельным Press Start 2P (в проект не добавлены внешние шрифты).
- Нет отдельной книжной раскладки для телефона: сцена 16:9 масштабируется целиком.
- MCP-пакет для Unity (`com.coplaydev.unity-mcp`, как в ace-arena) не подключён.
